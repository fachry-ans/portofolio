# Portfolio Muhammad Fachry Anshor

Website portfolio pribadi modern, responsive, dan tanpa framework.

## Struktur
- `index.html` — halaman utama
- `style.css` — UI, responsive layout, animasi
- `script.js` — dark/light mode, mobile menu, scroll reveal, active navigation
- `assets/profile.png` — foto profil

## Cara menjalankan
Cukup buka `index.html` di browser.

Untuk development lokal, bisa menggunakan VS Code + Live Server.

## Catatan
- Tidak membutuhkan database/backend.
- Email dan nomor telepon sudah dibuat sebagai link.
- Warna, teks, skill, pengalaman, dan foto dapat diubah langsung dari file HTML/CSS.
